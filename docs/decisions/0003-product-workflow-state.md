# ADR-0003：资源摘要与操作回执、编辑草稿分离

日期：2026-10-14。状态：采用。对应 CHORE-20261014-001，用户要求落实产品审查改进。

## 决定

- 日常入口仅资源、同步、贡献；首次连接位于工作空间管理，设置位于侧栏底部。用户级/项目级仍是 core 范围，只改解释，不改语义。
- renderer 拆为资源、设置、工作流和共享对话框组件，使用具体 DTO；设置草稿与 snapshot 分开，刷新保留编辑，离开明确保存/放弃。
- 贡献结果来自 core 已写入的 pendingPushes 与 lastPush 前后变化，不解析日志推测分支。失败仍返回失败及可用回执；新确认必须重新扫描。通用 Git 手动创建评审入口明确呈现。
- 资源元数据通过 yaml 解析，在主进程受控读取中形成摘要；仅删除合法 frontmatter 的展示，不改文件。格式错误保留原文和提示。搜索覆盖用途与部署工具。
- 只读 core 输出层增加既有 pendingPushes 与配置中的技能目标路径；路径留在可信进程。renderer 只收到资源 ID、摘要与核对结果。技能只核对 SKILL.md 正文，附件/其他类型不宣称已核对；越界或不可读目标显示未知。读取不迁移/fetch。
- 对话框使用背景 inert、循环焦点、Escape 关闭与返回触发按钮；辅助文字采用可读颜色，SVG 取代 Unicode 图标。
- 环境检查运行 git --version、gh --version/auth status，返回布尔状态与工具目录发现结果，不返回认证输出。目录存在不等于工具版本/运行时完整，向导仍要求用户核对。

## 保留的边界

预检仍可能迁移旧 hooks，因此保留独立许可，完成后明确阶段再确认应用。贡献仍为 core 全量提交，不提供无内核支持的假选择器；界面清楚列出限制。不增加业务内核、插件框架或身份托管，不承诺事务回滚、自动重试或灰度已完成。
