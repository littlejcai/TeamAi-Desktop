# 0.5.1 产品审查落实记录

2026-10-14，CHORE-20261014-001。范围：落实本次主干产品审查可在工程内解决的问题。状态：实现与本地最终验证完成，平台 CI 验证中。

| 审查问题 | 实现与验收方式 |
|---|---|
| 推送成功/评审失败只剩日志 | 读取 core 分支记录，展示状态、分支复制和仓库/评审入口；真实 HTTPS Git 部分失败断言实际分支与失效确认 |
| 刷新丢设置、离开无提醒 | 草稿独立；UI 验证刷新保留、离开对话框、取消与恢复已保存值 |
| 详情焦点逃逸 | 背景 inert、Tab/Shift+Tab 圈定、Escape 与焦点返回；真实 Electron 验证 |
| 辅助小字难读/图标方框 | 小字号文本颜色加深，统一 SVG；截图与对比度核对 |
| 卡片无用途、frontmatter 假标题 | 主进程解析 YAML 摘要，按用途搜索，详情只渲染正文，错误元数据保留原文 |
| 不知是否部署 | 技能 SKILL.md 与配置目标正文核对；其他类型/越界目标明确待核对，附件不在标记保证内 |
| 初始化前置条件不透明 | Git、GitHub 登录与工具目录检查，检测工具默认选择、角色分组/作用范围说明，完成后进入同步 |
| 同步信息与阶段混淆 | 本地 Git 信息折叠，预检完成状态、工具/范围摘要、忽略零项行；保留真实迁移许可 |
| 导航/指标噪声 | 三个日常入口，工作空间管理容纳连接团队，设置置底；首页用资源/待办摘要 |
| 页面状态与返回类型难扩展 | 资源/设置/工作流/对话框拆分、具体响应 DTO、草稿和操作结果分离 |
| 诊断只有日志 | 页内显示健康状态与完整诊断报告；日志按操作清理且滚动到最新 |

未伪造的验收：真实用户走查、10 人灰度、私有托管平台登录、macOS/屏幕阅读器、大规模资源与断网长耗时测试未由本轮自动验收替代。签名、自动更新和 Windows 完整 core 历史缺陷继续按既有任务跟踪。部分资源选择需后续 core 契约，不加入当前全量 push。

本地已执行：fork 类型/构建与 3 个真实读取测试通过；锁定依赖/library/WASM、桌面类型/构建、14 个服务测试通过；2 个真实 UI 主流程通过。最终两条 Electron 流程也已通过，覆盖设置保存/放弃与真实 doctor/日志保存：原生保存窗口在测试中自动选择隔离目标文件，未将此写为人工对话框验收。

验证与截图：完成后补充固定 CI 与本次截图路径。架构依据见 ADR-0003。
